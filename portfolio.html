Zomato Delivery
Analytics & Prediction

An end-to-end project exploring food delivery performance, analyzing factors that affect delivery time, and predicting delivery duration using machine learning.

View GitHub Project Explore Results

Project Overview

I used Python for data cleaning and exploratory analysis, PostgreSQL for querying delivery trends, XGBoost for delivery time prediction, and Power BI to present the findings in an interactive dashboard. The project focuses on understanding how traffic, weather, vehicle condition, and multiple deliveries relate to delivery performance.

What I Found

Traffic Conditions

Average delivery time ranged from 21.46 minutes under low traffic to 31.18 minutes under jam conditions.

Multiple Deliveries

Average delivery time was 22.88 minutes for orders with zero additional deliveries and 47.82 minutes for orders with three. These are observed associations in the dataset.

Weather & Festivals

Delivery times varied across weather conditions and festival periods in the dataset.

Project Workflow

  • Cleaned and prepared 45,584 delivery records.
  • Explored delivery trends and relationships using Python.
  • Queried delivery performance using PostgreSQL.
  • Trained and evaluated an XGBoost regression model.
  • Built a Power BI dashboard to explore delivery metrics.
  • Tested hypothetical scenarios for potential delivery-time reduction.

The optimization scenarios are estimates based on simplified assumptions, not measured improvements from a deployed system.
